# Demo District Anti-Bullying Dashboard Specification

## Dashboard Purpose

The Demo District Anti-Bullying Dashboard provides district leaders, principals, counselors, and safety teams with real-time visibility into bullying incidents, investigation outcomes, intervention effectiveness, compliance metrics, and school climate trends.
